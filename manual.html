1. Overview

Map in a Box is an accessible world map and local exploration program designed for blind and low-vision users. It runs on Windows and macOS.

The program combines global geography with street-level navigation. It is keyboard driven, works well with screen readers, and lets you move from the world map into street-level exploration without relying on a visual display.

The program has six main modes:

ModeWhat it does
Map modeExplore the world map by country, city, coordinates, and geographic features. The default mode on startup.
Street modeExplore streets, intersections, house numbers, and nearby points of interest at the local level.
Walking modeMove along a real street network with controlled turn choices at intersections, with optional POI announcements.
Free modeExplore nearby streets and points of interest relative to a heading, without being locked to a road.
ToolsRoute planning, detour calculation, toll comparison, meeting place finder, public transport journey planning, departure boards, flight search, hotel search, and Find Food.
Challenge gameA geography game that asks you to locate a named country on the world map by sound.

2. Starting out

When Map in a Box opens, it places you at your saved home location. If no home location has been set, the program prompts you to set one before continuing. Home can be changed at any time from the Settings dialog (Ctrl+,) using the Set Home Location button.

The main window contains a visual map canvas and a status area. Screen reader users interact primarily through spoken output and the keyboard — the map canvas is not required. All navigation, lookup, and mode-switching functions are keyboard driven.

You can use the shortcuts in Section 19, or access the same features from the menu bar with Alt.

3. Map mode

Map mode is the default. The arrow keys move a cursor across the world map. As you move, the program announces the country, city, region, body of water, or geographic feature at the cursor position.

Move with the arrow keys. Use smaller steps when you need fine positioning, larger steps for long jumps, and a directional jump when you want the nearest country in a given direction.

Press Shift+F8 to switch the map display between World and Country modes. World mode keeps the full global view as it is today. Country mode keeps the world map but reduces label clutter and focuses on the country you are in, along with its main state or province labels and a smaller set of nearby cities.

Map mode also includes global shortcuts for repeating the current position, reading coordinates, turning sounds on or off, opening Street Mode, opening Tools, and changing Settings. The map-specific shortcuts cover jumping to a place, postcode lookup, current region or country, nearby city, switching GeoFeatures on or off, and the regional information keys such as time, weather, airports, and currency. The quick reference at the end lists the full shortcut set.

For current-location information, the app can report the capital city, climate zone, time, timezone, sunrise and sunset, weather, air quality, nearest airport, overhead aircraft, coordinates, languages, and currency. Most of those require the internet.

If you prefer menus, the same features are available from the menu bar with Alt.

Spatial tones give you an audio sense of your position without speech. Pitch represents latitude and panning represents longitude. Settings lets you choose whether the tones are based on the world, the current country, or the current region.

4. Jumping to a place

Press J in map mode to open the jump dialog. Type a search term and press Enter. If multiple results are found, a list is presented — use the arrow keys to choose and press Enter to jump.

Accepted search terms include:

  • City names — e.g. Brisbane, London, Vancouver
  • Countries — e.g. Japan, New Zealand, South Africa
  • Coordinates — decimal degrees, e.g. -27.47, 153.03
  • Geographic features — major deserts, mountain ranges, reefs, gulfs, capes, and other named natural features

For search terms of four or more characters, a "Search online" option appears at the bottom of any results list, and is offered automatically if no local match is found. Online search uses OpenStreetMap's Nominatim service and returns a second list to pick from. Shorter terms with no local match return "not found". Jump is disabled during the geography challenge game.

5. Marks and destination

Marks let you measure the distance between two or more places. Map in a Box supports up to three marks — numbered 1, 2, and 3 — along with a single destination point. The idea is straightforward: drop a mark on each place you want to compare, set a destination as your fixed reference, and the app will tell you how far each mark is from it. Unlike favourites, which are permanent saved places, marks are temporary — they're there for a quick comparison and can be cleared when you're done.

To save a mark, move to the place you want to remember and press Ctrl+M. You'll be asked which slot to use — press 1, 2, or 3. To hear what's stored in a slot, press Ctrl+1, Ctrl+2, or Ctrl+3. When you no longer need a mark, press Ctrl+Shift+M and choose the slot to clear it.

To set your destination, move to the reference point and press Ctrl+D. If you'd prefer to promote one of your saved marks to the destination, press Ctrl+Alt+D and choose the slot. Press Ctrl+Shift+D at any time to hear where the destination is currently set.

With marks and a destination in place, press Ctrl+Shift+1, Ctrl+Shift+2, or Ctrl+Shift+3 to hear the distance and bearing from that mark to the destination.

6. Favourites

Favourites let you save and quickly return to frequently used places or points of interest.

They are stored locally and persist across sessions. You can add the current place or a selected point of interest, then return to it later from the favourites list.

7. Points of interest

Points of interest (POIs) include businesses, transport stops, parks, medical services, accommodation, and landmarks. POI data is sourced from OpenStreetMap by default. A HERE API key enables richer live detail such as opening hours, phone numbers, and ratings.

POIs are useful in both map and street exploration. In map mode they help you see what is nearby, and in street mode they let you inspect local places one by one.

When opening the POI list, you are prompted to choose a category:

  • All nearby
  • Food and drink
  • Shopping
  • Public transport
  • Trains and stations
  • Health and medical
  • Community and services
  • Arts, venues and landmarks
  • Parks and outdoors
  • Accommodation

Selecting a transit stop can open departure information where timetable data is available. POIs can be jumped to, explored in more detail, queried for address or contact details, and opened in a browser if a website is available.

8. Find food

Find Food searches for food and drink venues along a route — useful when you want to plan a stop on a longer journey. It lives in the Tools menu (F12); select Find Food from the list. For full details see section 13.9.

When you open it, you'll be asked to choose a starting point and then a destination. Each time, the app offers a short list of options: type an address, pick a saved mark, choose a favourite, or use your current position. Once both ends of the route are set, Map in a Box fetches the route and lists any food and drink venues found within 300 metres of it, ordered by where they appear along the way.

9. Satellite and Street View

Map in a Box can open satellite imagery and street-level photographs for the current position. Both require a Google API key. If a Gemini API key is also configured, the program asks for a spoken description of the image.

9.1 Satellite view

Satellite view shows an overhead image of the current position in an in-app dialog. The Gemini description appears below the image and is announced through the screen reader. It can describe terrain, land use, buildings, water, and vegetation. Without a Gemini key, the image still opens but the text field reads: "Satellite imagery loaded. A Gemini API key is required to fetch a visual description."

9.2 Street View

Street View fetches up to two ground-level photographs of the current location — one in each direction along the street — and displays them in an in-app dialog. The Gemini description appears below the images and is announced through the screen reader. With a Gemini key, it can describe building types, street layout, signage, access features, and surroundings. Without a Gemini key, the images still display but the text field reads: "Street View imagery loaded. A Gemini API key is required to fetch a visual description."

If no Google API key is configured, the program opens Mapillary in your browser as a fallback. If Google Street View has no coverage at the current location, the program falls back to satellite view instead.

Note: Both satellite and Street View open inside the app as dialogs, not in a browser. The Gemini description is announced by the screen reader as well as shown in the dialog text field. Mapillary is the only browser fallback.

10. Street mode

Press F11 from map mode to enter street mode at the current cursor position. Street data is downloaded from OpenStreetMap on demand and cached locally. The first visit to an area may take a few seconds to load depending on connection speed.

Street mode allows detailed local exploration: moving along roads, checking house numbers and intersections, looking up businesses, and getting walking directions.

Movement follows the street network, with finer or larger steps available when you need them. You can step through house numbers and intersections, turn onto cross streets, search for streets or addresses, hear the nearest cross street, open the POI list, and ask for walking directions to a typed address. Press F11 again when you want to return to map mode.

11. Walking mode

Walking mode simulates moving along a real street network. You travel forward and backward along the current street and choose which way to turn at intersections. Nearby points of interest can be announced automatically as you walk.

POI announcements while walking are configured in Settings. You can choose the category of POIs to announce, the detection radius (50, 80, or 120 metres), and whether the category label is included in each announcement.

12. Free mode

Free mode lets you explore an area relative to a heading, without being constrained to a road. You move forward along your current heading and can pan left or right to hear what is nearby on either side.

This mode is designed for heading-based exploration. You can move forward, listen for nearby places on each side, snap to nearby cross streets, reverse direction, inspect address numbers or POIs, and leave the mode when you want to return to the street view.

13. Tools menu

Press F12 in map mode to open the Tools menu. It collects the longer route and travel tools in one place. Some tools need marks, a destination, or API keys, and the program tells you what is needed when something is missing.

13.1 Detour Calculator

Compares a direct trip against a trip with one or more stop-offs, showing the extra distance and time each diversion adds.

  1. Enter your starting point.
  2. Enter your first stop-off, then your final destination.
  3. Add further stop-offs if needed — leave the prompt blank to finish.

Falls back to open routing without a Google key; turn-by-turn detail may be reduced.

13.2 Suburb Lister

Lists alternative routes between two points showing which suburbs or areas each passes through and whether toll roads are involved.

  1. Enter your starting point.
  2. Enter your destination.

13.3 Rendezvous Point

Finds a pickup, dropoff, or meeting point between two people. Select a mode in the dialog.

Pickup — a driver collects you en route to a shared destination. Enter the driver's start, the shared destination, and your location. Candidates are scored by minimising the driver's detour plus your travel to the pickup. Each result shows your distance to the point, the driver's distance from their start, and the remaining shared journey.

Dropoff — a driver drops you off en route to their own destination. Enter the driver's start, their destination, and your destination. Scoring favours points where the driver carries you further, penalising detours from the driver's route at 4× weight — a 5 km detour counts the same as 20 km of remaining travel for you. Each result shows how far the driver carries you, your remaining distance, and whether the point is on the driver's route or off it.

Meeting place — two people travelling toward each other. Enter both starting locations. Candidates are ranked by road distance from the true midpoint. Each result shows distance from each person and the offset from the exact halfway point.

All modes return up to six candidates, ranked best first.

13.4 Toll Compare

Compares the toll route against the toll-free alternative for the same corridor. Enter start and destination; results show distance, travel time, and toll cost. Toll pricing requires a Google API key — without one, only distance and time are shown.

13.5 Journey Planner

Plans a public transport trip between two addresses or stops.

  1. Enter origin and destination (address, stop name, or suburb).
  2. Choose timing: leave now, depart at, or arrive by.
  3. Enter a date and time if prompted.

Results include connections, total duration, and per-leg departure times. Requires a Google API key; no fallback.

13.6 Departure Board

Shows upcoming departures for transit stops near the current map position. Select from a list of nearby stops; results include service name, headsign, and departure time. Also accessible via Ctrl+Enter on a transit stop in the POI list.

Uses GTFS scheduled data by default. With a HERE API key, switches to live departures with platform numbers and real-time status.

13.7 Flight Search

Searches flights between two airports by name or IATA code. Returns up to 15 itineraries sorted by duration, with airline, departure and arrival times, and connections shown per leg. Requires a RapidAPI key (Timetable Lookup API, free tier available).

13.8 Hotel Search

  1. Enter a city.
  2. Select from matched locations.
  3. Enter check-in and check-out dates.

Results aggregate hotels for the city and show each hotel name and address. Selecting a hotel opens the hotel’s own website. Requires a RapidAPI key (Priceline API, free tier available).

13.9 Find Food

Find Food searches for food and drink venues within 300 metres of a route, ordered by where they appear along the way. Open the Tools menu with F12 and select Find Food.

  1. Choose a starting point — type an address, pick a saved mark, choose a favourite, or use your current position.
  2. Choose a destination the same way.
  3. Map in a Box fetches the route and lists food and drink venues found within 300 metres of it. Select a venue to hear its address; with a HERE API key you'll also get opening hours, phone number, and a link to its website.

If a GTFS transit route is active when you open Find Food, the search runs along that transit line rather than a road route.

14. Geography challenge game

The challenge game tests your knowledge of world geography by sound. The program names a country and you must locate it on the world map using movement and audio cues.

Note: Jump (J) is disabled during the challenge.

14.1 Audio cues

SoundMeaning
Map position toneThe normal spatial tone — tells you where you currently are on the world map.
Sonar pulseA centred pulse that rises in pitch as you approach the target country.
HeartbeatA low rhythmic beat that speeds up as the time limit approaches.
FanfarePlays when you successfully locate the target country.
BuzzerPlays when time runs out.

Direction mode (Map learning or Shortest globe) is configured in Settings under Challenge direction.

16. Internet and API keys

Core map features work from local bundled data and do not require an internet connection. The following features require internet access:

  • Weather and air quality
  • Timezone and sunrise/sunset
  • Wikipedia summaries
  • Country facts (live data)
  • POI lookups and detail
  • Street data downloads
  • Transit timetable data
  • Route and navigation calculation
  • Flight and hotel search
  • Satellite and Street View imagery
  • Overhead flight information

16.1 API keys and what they unlock

KeyWhere to get itWhat it enables
GoogleGoogle Cloud ConsoleSatellite imagery, Street View, Google Maps walking navigation, and proximity-aware address search
GeminiGoogle AI Studio (free)Spoken descriptions of satellite and Street View images, POI summaries, and transit questions
HEREHERE DeveloperLive POI details including phone number, website, opening hours, and ratings; category-filtered POI browsing with better commercial coverage than OpenStreetMap; turn-by-turn walking navigation; real-time departure boards showing next services, platform, and transport mode (rather than scheduled timetable only)
OpenRouteServiceopenrouteservice.orgWalking and driving distance calculation between marks
AviationStackaviationstack.comAirport arrival and departure boards, live flight information
OpenSkyopensky-network.org (free)Overhead flight destination lookup
RapidAPIrapidapi.comFlight search (Timetable Lookup API) and hotel search (Priceline API)

16.2 Google and HERE in more detail

Google API key — enables satellite imagery and Street View inside the app as dialogs, not in a browser. Satellite view shows an overhead image of the current position. Street View fetches up to two ground-level photographs of the location. Google Maps navigation provides turn-by-turn walking directions with named street instructions. Without a Google key, navigation falls back to OpenStreetMap routing, Street View falls back to Mapillary in a browser, and satellite imagery is unavailable.

HERE API key — HERE is optional. Without it, the app uses OpenStreetMap data throughout and remains fully functional. With a HERE key, three things improve: POI details, HERE walking directions, and live departure boards. HERE accounts are free to create but require registration and may involve follow-up contact from HERE's commercial team.

16.3 What changes when a key is missing

Missing keyEffect
GoogleSatellite imagery is unavailable. Street View falls back to Mapillary in a browser. Google Maps navigation is unavailable; walking routes use OpenStreetMap instead.
GeminiNo spoken descriptions for satellite or Street View images, POI summaries, or transit questions.
HEREPOI details use OpenStreetMap only. Walking navigation uses OpenStreetMap routing. The departure board uses GTFS scheduled timetables.
OpenRouteServiceDistance calculations between marks are unavailable.
AviationStackAirport arrival and departure boards are unavailable.
OpenSkyOverhead flight destination lookup is unavailable.

When a key is missing and a fallback exists, Map in a Box uses the fallback silently. When no fallback is available, the program explains what is needed.

17. Common workflows

17.1 Find a city

  1. Press J.
  2. Type the city name and press Enter.
  3. Choose from the results list if more than one match is found.
  4. Press Enter to jump.

17.2 Get facts about a country

  1. Move the cursor onto the country.
  2. Press F6 for area, population, and regional data.
  3. Press Shift+F1 for the capital city.
  4. Press L for languages, $ for currency.

17.3 Explore a neighbourhood at street level

  1. Jump to the city with J.
  2. Press F11 to enter street mode. Wait for data to load.
  3. Use arrow keys to move, S to search for a street by name, P for nearby POIs, A for address lookup, and Ctrl+G for walking directions.

17.4 Plan food stops along a route

  1. Move to your departure point. Press Ctrl+M then 1 to save it as mark 1.
  2. Move to your destination. Press Ctrl+M then 2 to save it as mark 2.
  3. Press F12, choose Find Food, select mark 1 as the starting point and mark 2 as the destination. Review the list of food and drink venues along the route.

17.5 Compare pickup points for a single destination

  1. Move to each pickup point and press M, storing each as mark 1, 2, and 3.
  2. Move to the destination and press D.
  3. Press Alt+1, Alt+2, and Alt+3 to compare distance and bearing from each mark.

17.6 Play the geography challenge

  1. Press F10. The program names a target country.
  2. Move with the arrow keys. Use the map-position tone to track where you are and the sonar pulse to judge how close you are to the target.
  3. Press Shift+F10 or R at any time to hear the target name again.

18. Troubleshooting

18.1 First launch on macOS — app blocked by Gatekeeper

macOS blocks apps from developers who have not paid for Apple's code signing programme. To open Map in a Box for the first time, use the install script included in the zip:

  1. Extract the downloaded zip. You will find MapInABox.app and install-macos.sh in the same folder.
  2. Open Terminal (Applications → Utilities → Terminal, or Spotlight search for Terminal).
  3. Type bash (with a space after), then drag the install-macos.sh file into the Terminal window. Press Enter.
  4. The script removes the restriction, copies the app to your Applications folder, and opens it.

After running the script once, you can open Map in a Box from your Applications folder normally — the script does not need to be run again.

Alternatively, in Terminal:

xattr -rd com.apple.quarantine /path/to/MapInABox.app

18.2 First launch on Windows — SmartScreen warning

Windows may show a SmartScreen warning the first time you run the installer because the app does not yet have a widespread download history. This warning will reduce and eventually stop appearing as more people download the app. To proceed:

  1. When the SmartScreen dialog appears, press Tab to reach the More info link and press Enter.
  2. Press Tab again to reach the Run anyway button and press Enter.
