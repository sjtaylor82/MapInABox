1. Overview

Map in a Box is an accessible world map and local-exploration program for blind and low-vision users. It runs on Windows and macOS.

Explore the world by country, city, or street; find nearby places; and plan journeys. A sighted user can follow the exploration on the visual map.

The main parts of the program are:

Map in a Box modes
ModeWhat it does
Map modeExplore where countries, cities, and geographic features are in relation to one another.
Street modeDrop to the neighbourhood level and explore streets, intersections, numbers, and nearby points of interest in detail.
Walking modeMove along a real street network with turn choices at intersections, plus optional POI announcements as you go.
Free modeExplore nearby streets and points of interest relative to a heading, without being locked to a road.
ToolsPlan and compare routes, meeting places, public transport, flights, hotels, food stops, and rides.
Challenge gameA geography game where you locate a named country on the world map by ear.

2. Starting out

Map in a Box opens at your saved home location. If no home location is set, it asks you to choose one. Change it from Settings (Ctrl+,) with Set Home Location.

The main window shows your exploration visually so a sighted teacher, family member, or support person can follow along.

New users can explore the menu bar with Alt instead of memorising shortcuts. The complete shortcut tables are in Section 20.

3. Map mode

Map mode is the starting point for world exploration. The arrow keys move your position across a two-dimensional map. As you move, Map in a Box announces the current country, city or suburb and nearby landmarks, borders, and bodies of water.

Use the arrow keys for normal movement, Shift+Arrow for smaller steps, and Ctrl+Arrow for larger steps. Use Ctrl+Alt+Arrow to jump to the nearest foreign country in that direction.

If demonstrating to a visual learner or educator, press Shift+F8 to switch the map display between World and Country modes. World mode is the default global view, while Country mode fits the current country to the map. Use Ctrl+Plus and Ctrl+Minus for geographic visual zoom from 1x through 128x; Ctrl+0 returns to 1x. Closer Country views progressively show populated places, but never load or draw streets.

From map mode, you can quickly check your position, coordinates, postcode, local time, timezone, air quality, weather, nearby airports, and currency. See Section 20 for the full list.

These commands are also available from the menu bar.

Spatial tones provide an audio sense of global or regional position. Pitch represents latitude and stereo position represents longitude. Country sound profiles also help distinguish neighbouring countries. These cues can support geography and HASS lessons.

3.1 Country sounds and custom sounds

Country and region sounds make borders easier to recognise without repeatedly checking a name. Teachers and families can replace them with familiar cultural, environmental, or classroom sounds to create memorable audio associations.

Map in a Box comes with sounds for countries and regions. An update may change these built-in sounds and their credits file, credits.txt. Keep personal sounds in the user folders described below, where an update will not overwrite them.

To use your own sounds, place them in the user sound folders created by Map in a Box:

  • Windows portable: Data\sounds\countries or Data\sounds\regions, beside the portable program.
  • Installed Windows: %APPDATA%\MapInABox\sounds\countries or %APPDATA%\MapInABox\sounds\regions.
  • macOS: ~/Library/Application Support/MapInABox/sounds/countries or ~/Library/Application Support/MapInABox/sounds/regions.

Name a custom file after the country or region in lowercase, replacing spaces with underscores; for example, new_zealand.ogg or south_america.mp3. You can use OGG or MP3. If both exist, Map in a Box uses the OGG file. Your sound takes priority over the built-in sound. Delete your file to restore the built-in sound or the usual sound for that region.

3.2 Instructor-created maps

Instructor-created maps let someone explore a place that an ordinary street map cannot describe well. An educator, orientation and mobility specialist, or family member can map a classroom, school, building, station, shopping centre, event layout, or simple route. A learner can practise the layout independently, compare routes between named places, and become familiar with it before a visit.

The creator decides which paths are connected and which places are announced. This is useful for teaching a specific safe or permitted route without unrelated map detail. Multi-floor maps can represent different levels of a building, and the portable .miabmap file can be shared with another Map in a Box user.

Select File, Create Map File to draw a simple map. Begin with a blank page or import a JPG, PNG, or PDF as a visual guide. A multi-page PDF can be imported as separate floors. Use the floor selector in the builder, draw the paths students may travel, select Add a place, click its position, and enter its name. Test a route, then save the portable .miabmap file. Select File, Edit Map File to change an existing map made from any supported source.

Select File, Open Map File to explore one. The arrow keys move only along connected drawn paths with spatial sound and announce nearby labelled entrances and places. Press Ctrl+Page Up or Ctrl+Page Down to explore another floor. Press Ctrl+Home or Ctrl+End for the top or bottom accessible point. Press Ctrl+R to choose two places, hear their crow-flight relationship, calculate a route that follows only the connected drawn paths, or explore that route with Journey Planner sound. Nearby but unconnected paths—such as parallel shopping-centre aisles—are never treated as connected. Press Escape to close the map file.

Closing the map file restores the previous world-map position. Street, Walking, and Free modes do not operate inside an instructor-created map.

3.3 Visual Assist mode

Visual Assist lets a sighted teacher, family member, orientation specialist, or support person follow while a blind user controls Map in a Box. Its larger, high-contrast map can also help low-vision users.

Press F9 to turn Visual Assist on or off. It enlarges the map and reduces competing information around it. The current position has a high-contrast halo that pulses after movement, while a subdued trail shows recent movement. A persistent callout names the current location.

The display also shows coordinates, the map view and zoom level, north, and any destination marker. When you ask for information such as your location or country facts, it appears as a large high-contrast caption for seven seconds. Visual Assist does not change the keyboard controls or screen-reader announcements.

4. Jumping to a place

Jumping is the quickest way to begin exploring somewhere far from your current position. It avoids crossing the world manually and accepts familiar place names as well as exact coordinates.

Press J in map mode to open the jump dialog. Type what you're looking for such as a landmark, city or country, and press Enter. If there's more than one match, you'll get a list — arrow through it and press Enter to jump.

You can type:

  • City names — e.g. Brisbane, London, Vancouver
  • Countries — e.g. Japan, New Zealand, South Africa
  • Coordinates — decimal degrees, e.g. -27.47, 153.03
  • Geographic features — major deserts, mountain ranges, reefs, gulfs, capes, and other named natural features

For searches of four or more characters, Search online appears at the bottom of the results and runs automatically when there is no local match. It uses OpenStreetMap's Nominatim service and may present another results list. Shorter terms with no local match return “not found.” Jump is unavailable during the geography challenge.

Press Ctrl+H to revisit any of your last five jumps without typing the search again.

5. Marks

Use marks when you want to compare up to three places or check the rough distance between them without saving permanent favourites. Think of them as numbered sticky notes that you can place, revisit, and clear when you are finished.

To save one, move to the place you want to remember and press Ctrl+M. You'll be asked which slot to use — press 1, 2, or 3. To hear a mark's distance and compass direction from your current position, press Ctrl+1, Ctrl+2, or Ctrl+3. To jump back to one, press Ctrl+J and pick the slot if asked. Done with a mark? Press Ctrl+Shift+M and choose the slot to clear it.

You can press Shift+Alt+M to hear the distance and compass direction between every pair of stored marks at once.

6. Favourites

Favourites save repeated typing and searching for places you visit often, such as home, school, work, a station, or a relative's address. Unlike temporary marks, favourites remain available in later sessions.

7. Points of interest

Points of interest — POIs — cover businesses, transport stops, parks, medical services, accommodation, and landmarks. OpenStreetMap supplies the standard results. A HERE API key can add opening hours, phone numbers, and ratings.

In map mode, POIs tell you what is nearby. In street mode, you can inspect them one at a time and hear any available address, phone number, opening hours, or website.

When you open the POI list, you'll be asked to pick a category:

  • All nearby
  • Food and drink
  • Shopping
  • Public transport
  • Trains and stations
  • Health and medical
  • Community and services
  • Arts, venues and landmarks
  • Parks and outdoors
  • Accommodation

Map in a Box can download public-transport timetables and read them as a list. When it has a timetable for a selected stop, you can check its departures.

After seven days, Map in a Box treats a saved timetable as out of date. When you next need it, the app asks whether to download a newer copy. Choose No if you need to continue with the saved timetable. The Area Downloader updates all out-of-date timetables for the region you select, without asking about them one at a time.

8. Find food

Find Food lists food and drink venues near a route in travel order. Open it from the Tools menu (F12). See section 14.9 for instructions.

9. Satellite and Street View

Imagery lets a sighted teacher, support person, or low-vision user examine building approaches, road layouts, terrain, vegetation, and other details that map labels may not capture. With a Mistral key, a blind user can hear a description of the same image.

Map in a Box can show satellite images and street-level photographs for where you are on the map. Satellite images and Google Street View inside Map in a Box require a Google API key. Mapillary opens street imagery in a browser without a key. Add a Mistral key to hear a description of an image.

9.1 Satellite view

Satellite view opens an overhead image of your current position inside Map in a Box. With a Mistral key, you can also hear a description of the terrain, land use, buildings, water, and vegetation. Without that key, the image still opens for a sighted person to examine.

9.2 Street View

Street View shows up to two ground-level photographs, looking in opposite directions along the street. With a Mistral key, Map in a Box describes features such as buildings, the street layout, signs, access features, and the surroundings. Without a Mistral key, the photographs still open but are not described.

Choose the street-image service in Settings. Google Street View requires a Google API key. Mapillary opens in your browser and does not require a key. If Google has no Street View photograph for the location, Map in a Box tries satellite view.

10. Street mode

Use street mode to understand how a neighbourhood fits together before travelling there: which roads connect, where intersections occur, which address numbers are nearby, and what businesses or facilities line the route.

Press F11 from map mode to enter street mode where you are. Map in a Box downloads the area's streets from OpenStreetMap on the first visit and saves them for later visits.

This is where the app shifts from overview to real-world detail: moving along roads, checking numbers and intersections, looking up businesses, and getting walking directions.

10.1 Moving along a street

Street mode lets you follow the order of addresses and intersections without estimating distances with the arrow keys.

  • Press Page Up to move toward the previous or lower known address and Page Down to move toward the next or higher one.
  • Press Ctrl+F12 to choose what those keys visit: all known addresses, with POI names announced where present, or only addresses and locations that have a POI.
  • If several POIs share an address, use Shift+Page Up and Shift+Page Down to hear each one.
  • Press Ctrl+Alt+F12 to include all numbers, odd numbers, or even numbers.

10.2 Intersections and turns

Press Ctrl+Page Up or Ctrl+Page Down to move to the previous or next intersection on the current street. At an intersection, press Ctrl+Shift+Page Down to turn onto the cross street. Press Ctrl+Shift+Page Up to return to the street you left.

Press S to search for a street, A to look up an address, or X to hear the nearest cross street. Press F11 to return to map mode.

10.3 Walking directions

After requesting walking directions with Ctrl+G, move through the turn instructions one at a time. If you have a Mistral key, press Shift+I for a more conversational description of the walk. Use Up and Down to move through it and I to repeat the current part. Press Escape to return to the ordinary turn list without cancelling the route. If the description cannot be created, the ordinary directions remain available.

10.4 Australian address data

In Australia, Map in a Box can use the Geocoded National Address File (GNAF) for street numbers and address lookup. GNAF combines address data from state and territory governments and often has more complete residential numbering than OpenStreetMap.

While browsing within Australia, Ctrl+Shift+F12 tells you whether GNAF address data is on or off; press it again within five seconds to change it. GNAF tends to have more residential numbers. OpenStreetMap may work better in business and shopping areas because its businesses and buildings often have address tags. If address stepping skips businesses or keeps landing on residential numbers, turn GNAF off and turn it on again when you return to a residential area.

11. Downloading a city's suburbs in one go

The Area Downloader lets you download several suburbs or a region's public-transport timetables before you need them. This means less waiting during a lesson, demonstration, or later exploration, and gives you a saved copy when the internet may be slow or unavailable.

Street data normally downloads when you enter street mode. Use the Area Downloader when you want several suburbs ready before exploring them.

Press Ctrl+Shift+F11 to open the Area Downloader. Choose a country and state or region, then either download its public-transport timetable data directly or find individual suburbs for street and address data.

  1. Country. Pick from the worldwide list. Map in a Box starts with the country you are currently exploring if it can.
  2. State, region, or postcode range. Choose a state/region from the list, or type a postcode range instead (useful when you want something more precise than a whole state).
  3. Suburbs. Map in a Box lists the suburbs and towns found by OpenStreetMap. Move through the list and tick the ones you want. Type part of a name in the filter box to shorten a long list.
  4. Confirm. Review your selections and the estimated time, then start the download.

After confirmation, downloading continues in the background and completed suburbs become available for exploration. Loading another new area at the same time may make both downloads slower.

Once a suburb has downloaded, street mode uses the saved copy in the same way as an area you visited earlier.

12. Walking mode

Walking mode helps you learn the sequence of streets and turns in an area rather than moving freely across a map. It can support route familiarisation by letting you practise decisions at intersections and hear nearby points of interest.

It simulates moving along a real street network. You can travel forward and back along the current street and choose your turn at each intersection, with nearby points of interest optionally announced as you go.

To choose which nearby points of interest are announced, open Settings with Ctrl+, and use the walking options on the General tab.

13. Free mode

Free mode is useful when you want to understand what lies ahead, left, or right without being constrained to a particular road. It supports orientation around open areas, nearby streets, and groups of points of interest.

Free mode lets you explore relative to a heading without following the street network. Move forward with Up, and use Left or Right to hear points of interest on either side.

You can also move backwards, reverse direction, snap to a nearby cross street, check address numbers, and return to street mode.

14. Tools menu

The Tools menu helps answer practical travel questions: Which route is quicker? Where could two people meet fairly? What services connect two cities? What food is near the journey? Press F12 in map mode to open it.

A tool may ask you to set marks, choose a destination, or add an API key before it can continue. If a key is missing, Map in a Box tells you which one you need.

In Education, a computer administrator chooses which planning tools students can use. Hotel Search, Virgin Australia Booking, and Order an Uber are not included. Students also cannot open food websites, reviews, or menu links from Map in a Box.

14.1 Detour Calculator

Compares a direct driving trip with a trip containing one or more stops. The result shows the extra distance and time added by the stops.

  1. Enter your starting point.
  2. Enter your first stop-off, then your final destination.
  3. Add more stop-offs if you like — leave the prompt blank to finish.

You do not need a Google key. Without one, Map in a Box uses a free open routing service, which may provide fewer turn-by-turn details.

14.2 Suburb Lister

Use Suburb Lister to understand the broad geography of a drive or compare alternatives without reading every turn. It lists the suburbs or areas each route passes through and identifies toll roads.

  1. Enter your starting point.
  2. Enter your destination.

14.3 Shared Journey

Shared Journey helps two people decide where to meet before an event or where to part after it. The best choices are shown first.

Shared Journey says Building list... while it compares the routes. A free open-data route can take longer to calculate than a Google route.

Map in a Box uses its included place list for familiar suburb and city names. It uses your chosen online map service for full addresses and road calculations.

Meet halfway asks where you and your friend are starting. It lists meeting areas closest to halfway by road and shows the approximate travel for each person.

Meet before an event

  1. Enter your starting place.
  2. Enter your friend's starting place.
  3. Enter the event location.

Map in a Box follows both journeys toward the event and looks for fair places where the routes come together. Places within 1.5 kilometres are treated as natural meeting choices. When the routes are farther apart, MIAB may suggest a place between them, with each person moving no more than 4 kilometres toward it. These choices are clearly marked as detours. Each choice tells you roughly how long each person travels before meeting and how long remains to the event. Tab to Why these choices to read which side of the event each person approaches from and why the choices were made.

Friend is driving after an event

  1. Enter the event location.
  2. Enter your destination.
  3. Enter your friend's destination.

Map in a Box looks for places where your friend can drop you off without going far out of their way. Each choice tells you how far you travel together, how far each person has left, and whether the stop is already on your friend's way.

Sharing a taxi after an event uses the same three places. It compares both destination orders to find the shorter taxi trip. When the longer order adds at least 1 kilometre or 5 minutes, the result says how much extra it adds. For either driving choice, you can optionally enter a station, interchange, or other drop-off that you want included in the comparison.

Sometimes both routes stay apart until close to the event. In that case, Map in a Box keeps the event as the simplest choice and may also offer nearby alternatives when each person can reach the meeting area with a modest detour.

14.4 Toll Compare

Compares toll and toll-free driving routes between the same start and destination. Results show distance and travel time. Toll pricing requires a Google API key.

14.5 Journey Planner

Compares ways to travel between two addresses, stops, cities, or coordinates. In Settings, choose either Rome2Rio or Google Maps as the transport source. Driving has a separate source setting.

  1. Enter origin and destination (address, stop name, or suburb).
  2. Choose transport options, walking directions, or driving directions. Walking appears only for trips of 25 kilometres or less and requires a Google key.
  3. Enter a travel date or time when asked.

Rome2Rio is the default and needs no API key. It combines buses, trains, flights, ferries, walking, and driving into possible long-distance journeys. A result may name the operators, service numbers, places where you change, total travel time, and estimated price. Departure times are not available for every route.

Google Maps requires a Google API key. Its transit results can include dated departure and arrival times, connections, and platform information. Google is also required for Journey Planner walking directions, which are offered only for shorter trips.

Driving directions use the free OpenStreetMap and OSRM services by default. Results can include alternative routes, distance, travel time, major roads, towns, toll information, and spoken steps. If you have a Google key and want routes that take current traffic into account, choose Google as the driving source in Settings. Saving a Google key does not change this choice automatically.

For a driving or walking result, Tab to Explore Path to follow its geographic shape. Up and Down move along the route; Home and End jump to the endpoints. In driving routes, Page Up and Page Down move by larger sections. In walking routes, they jump between turn instructions and the path is sampled at walking scale. The optional spatial-audio checkbox tracks progress across the route. Escape stops the path audio, restores the previous map position, and returns to the journey results.

14.6 Departure Board

Enter a country and a location, such as a suburb, stop name, or address. Departure Board lists stops near that location. Choose a stop to hear its upcoming services, destinations, and departure times. You can also open departure information with Ctrl+Enter on a transit stop in the POI list.

Choose the source in Settings. GTFS finds nearby stops from downloaded timetable data and requires no API key. Google Places requires a Google API key and can find a wider selection of station names; Map in a Box then matches the selected station to a downloaded GTFS timetable for its departures.

14.7 Flight Search

Use Flight Search to compare possible flights and connections without opening several airline sites. Search by airport name or three-letter IATA code. Results show up to 15 itineraries, shortest first, with airlines, departure and arrival times, and connections. It requires a RapidAPI key and a subscription to the Timetable Lookup API.

14.8 Hotel Search

Hotel Search lets you compare accommodation in an accessible list instead of working through a visual booking site. It gives the names and addresses of hotels in a city, then opens the selected hotel's website for details or booking.

  1. Enter a city.
  2. Select from the matched locations.
  3. Enter check-in and check-out dates.

It requires a RapidAPI key and a subscription to the Priceline API.

To read TripAdvisor reviews, use the same RapidAPI key and subscribe to the Tripadvisor COM API. You can then choose Get TripAdvisor Reviews for a selected hotel.

14.9 Find Food

Find Food searches for food and drink venues within 300 metres (about 980 feet) of a route and lists them in travel order.

  1. Choose a starting point — type an address, pick a saved mark, choose a favourite, or use your current position.
  2. Choose a destination the same way.
  3. Map in a Box fetches the route and lists food and drink venues within 300 metres (about 980 feet) of it. Select one to hear its address; with a HERE API key you also get hours, phone number, and a website link.

If a GTFS transit route is active, press Ctrl+Alt+F to find food near that transit journey instead of a road route.

14.10 Virgin Australia Booking

Virgin Australia Booking provides a shorter, screen-reader-friendly flight-search form, avoiding the need to find and complete the search fields on the full Virgin Australia website.

  1. Choose a one-way or return trip.
  2. Choose the origin, destination, and travel dates.
  3. Choose the numbers of adults, children, and infants.
  4. Select Open Virgin Australia.

Your browser opens the Virgin Australia flight-selection page with the search details filled in. Check the available flights and fares, then complete the booking on the Virgin Australia website. Map in a Box does not purchase a ticket or receive your payment details.

14.11 Order an Uber

Order an Uber hands a ride request to Uber with the pick-up point and destination already filled in. Open the Tools menu with F12 and pick Order an Uber.

  1. Choose a pick-up point — type an address, pick a saved mark, choose a favourite, or use your current position.
  2. Choose a destination the same way.
  3. Your browser opens Uber with both points set. Sign in to your Uber account if asked, then choose a car type, check the price, and confirm the ride in Uber.

No Uber API key is needed and Map in a Box never sees your Uber account: the app only builds the link. Nothing is booked until you confirm inside Uber.

If the pick-up and destination fields are empty, sign in to Uber and run the tool again.

15. Geography challenge game

The challenge game helps you practise world geography by ear. Map in a Box names a country, and you use the spatial tone and distance cues to find it before time runs out.

Note: Jump (J) is switched off during the challenge, so you must navigate to the country.

This tab lists timetable feeds already installed on the device, including their provider, age, and size.

  • Update Feed Index downloads the latest directory used to find public-transport feeds. It does not update installed timetables.

16.3 API Keys tab

Enter API keys for optional online services here. See Section 17 for what each one adds. Each field says saved or not set. Clear a service's Use checkbox to stop using it without deleting the saved key.

By default, both installed and portable copies protect keys with Windows Credential Manager or macOS Keychain. A portable user can instead keep keys in the portable Data folder, but they will be readable by anyone who can open or copy that folder. Map in a Box warns before making this change.

16.4 Logging tab

Choose which diagnostic events are written to miab.log. Enable extra categories when troubleshooting; verbose logging produces the most detail.

16.5 Keystroke Manager and other buttons

Keystroke Manager lets you find a commonly used command and change its shortcut. You can also remove a shortcut or restore the original one. If another command already uses your chosen key in the same mode, Map in a Box names that command and asks whether you want to move the key. The same key can do different things in Map and Street modes.

Movement keys and menu shortcuts remain fixed so navigation and visible menu labels stay predictable.

16.6 Education Admin tab

This tab appears only in Education. It shows the planning tools available to students. A computer administrator can turn each permitted tool on or off. Windows or macOS asks for administrator approval before applying the choices to everyone who uses that computer.

Hotel Search, Virgin Australia Booking, and Order an Uber cannot be enabled. If the saved school policy cannot be read, Map in a Box makes only the default approved tools available.

17. Internet and API keys

Some parts of Map in a Box work from information already on your computer. These tasks need an internet connection:

  • Weather and air quality
  • Timezone and sunrise/sunset
  • Wikipedia summaries
  • POI lookups and detail
  • Street data downloads
  • Transit timetable data
  • Route and navigation calculation
  • Flight and hotel search
  • Satellite and Street View imagery
  • Overhead flight information

17.1 What each API key adds

Each saved API service has a Use checkbox in Settings. Clear it to stop using that service without deleting its key or sign-in details. Select it again to resume the service.

Installed versions keep API keys in the computer's secure credential storage. Portable MIAB normally does the same, so the keys stay on that computer when the portable folder is moved. Portable users may instead choose to store keys as plain text in the portable Data folder. This makes the keys portable, but anyone who can access or copy that folder can read them. MIAB warns before enabling this choice. In Education, a computer administrator must allow plain-text storage before it can be selected.

17.2 Google and HERE in more detail

Google API key — shows satellite images and Google Street View inside Map in a Box. It also adds Google walking routes, transit results, departures, nearby address searches, and optional traffic-aware driving. Without the key, Map in a Box can use OpenStreetMap for walking routes and Mapillary for street images. Satellite images are not available.

HERE API key — adds HERE POI details and walking routes. Without it, Map in a Box can use OpenStreetMap for those tasks. A HERE account requires registration.

18. Common workflows

18.1 Find a city

  1. Press J.
  2. Type the city name and press Enter.
  3. Choose from the results list if there's more than one match.
  4. Press Enter to jump.

18.2 Get facts about a country

  1. Move the cursor onto the country.
  2. Press F6 for area, population, and regional data.
  3. Press Shift+F1 for the capital city.
  4. Press L for languages, $ for currency.

18.3 Explore a neighbourhood at street level

  1. Jump to the city with J.
  2. Press F11 to enter street mode. Give it a moment to load.
  3. Use the arrow keys to move, S to search for a street by name, P for nearby POIs, A for address lookup, and Ctrl+G for walking directions.

18.4 Get ready to explore a whole city ahead of time

  1. Press Ctrl+Shift+F11 to open the Area Downloader.
  2. Pick a country, then choose a state or region. You can enter a postcode range where supported.
  3. Tick the suburbs you're interested in from the list, then press confirm.
  4. Return to the map while downloading continues in the background.

18.5 Plan food stops along a route

  1. Move to your departure point. Press Ctrl+M then 1 to save it as mark 1.
  2. Move to your destination. Press Ctrl+M then 2 to save it as mark 2.
  3. Press F12, choose Find Food, select mark 1 as the start and mark 2 as the destination, and look over the venues along the way.

18.6 Compare distances and directions between marked places

  1. Move to each place and press Ctrl+M, saving them as marks 1, 2, and 3.
  2. Press Shift+Alt+M to hear the distances and compass directions between all three.

18.7 Play the geography challenge

  1. Press F10. The program names a target country.
  2. Move with the arrow keys — the map-position tone tells you where you are, and the sonar pulse tells you how close you're getting.
  3. Press Shift+F10 at any time to hear the target name again.

18.8 Open a business website instantly

  1. Find a business in the POI list or in street mode.
  2. Press Ctrl+Alt+4 to hear the saved website field. In the Pro edition, Ctrl+W opens the site in your browser; external POI website launching is unavailable in the Education edition.
  3. Can't find a site straight away? The app falls back to a web search so you're not stuck.

19. Troubleshooting

19.1 First launch on macOS — app blocked by Gatekeeper

macOS blocks apps from developers who haven't paid for Apple's code-signing programme, which includes us for now. To open Map in a Box the first time, use the install script that comes in the zip:

  1. Extract the downloaded zip — you'll find MapInABox.app and install-macos.sh sitting together.
  2. Open Terminal (Applications → Utilities → Terminal, or search for it with Spotlight).
  3. Type bash (with a space after it), then drag install-macos.sh into the Terminal window and press Enter.
  4. The script clears the restriction, copies the app to your Applications folder, and opens it.

After that first run, you can open Map in a Box from Applications like any other app — no need to run the script again.

Or, if you'd rather do it directly in Terminal:

xattr -rd com.apple.quarantine /path/to/MapInABox.app

19.2 First launch on Windows — SmartScreen warning

Windows may show a SmartScreen warning the first time you run the installer. To continue:

  1. When the SmartScreen dialog appears, press Tab to reach More info and press Enter.
  2. Press Tab again to reach Run anyway and press Enter.
