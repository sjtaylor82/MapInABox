1. Overview

Welcome to MapInABox, an accessible world map and local exploration program built for blind and low-vision users. It runs on Windows and macOS, and it's meant to make geography easy, immediate, and even a little bit fun.

It's entirely keyboard driven and built around screen readers from the ground up. That's right, nothing here depends on seeing a screen. You can jump to a place, check what businesses are nearby, open a website, or drop all the way down to street level and start walking the neighbourhood, all without leaving the keyboard.

Six main modes make up the program:

ModeWhat it does
Map modeRoam the world by country, city, coordinates, and geographic feature. This is where Map in a Box's global reach really shows.
Street modeDrop to the neighbourhood level and explore streets, intersections, numbers, and nearby points of interest in detail.
Walking modeMove along a real street network with turn choices at intersections, plus optional POI announcements as you go.
Free modeExplore nearby streets and points of interest relative to a heading, without being locked to a road.
ToolsRoute planning, detour calculation, toll comparison, shared-journey help, public transport journeys, departure boards, flight search, hotel search, Find Food, and Order an Uber.
Challenge gameA geography game where you locate a named country on the world map by ear.

2. Starting out

When Map in a Box opens, it drops you at your saved home location. If you haven't set one yet, it'll ask you to before continuing — and you can change it any time from Settings (Ctrl+,) with the Set Home Location button.

Although the main window has a visual map canvas and a status area, you don't need to be able to see either.

An attempt has been made to make the shortcuts in Section 20 as comprehensive as possible, however you can reach the same features from the menu bar with Alt if that's easier to explore initially.

3. Map mode

Map mode is where you land by default, and is, in essence, the heart of the application. The arrow keys move your position across a virtual 2-dimensional map of the world and. As you explore, the program tells you the city or suburb of the country you're currently navigating. In addition, you'll hear about neighbouring landmarks, countries, and bodies of water,. You'll find that a mental picture of where things are builds up almost immediately.

Move across the map by using the arrow keys, adding shift or control where appropriate for smaller or larger jumps respectively. You can even virtually jump over a body of water into a neighbouring country if you wish, by using control+alt with arrow keys

If demonstrating to a visual learner or educator, press Shift+F8 to switch the map display between World and Country modes. World mode is the default global view, while Country mode fits the current country to the map. Use Ctrl+Plus and Ctrl+Minus for geographic visual zoom from 1x through 128x; Ctrl+0 returns to 1x. Closer Country views progressively show populated places, but never load or draw streets.

Map mode also contains a host of useful lookups which can be activated with a single key press, including repeating position, announcing coordinates, toggling sounds on/off, postcode lookup, time and timezone check, air quality index, weather lookup, nearest airports,, and country currency. The full list is in Section 20, but by now, you've probably realised that Map Mode is a launchpad for whatever you want to do next, and that MapInABox really contains a plethora of tools..

Prefer menus over remembering keystrokes? Never fear. Everything here is also reachable from the menu bar with Alt.

Let's talk about what happens when you navigate the world. Spatial tones give you an audio sense of your global or regional position. This is achieved via higher or lower pitches for latitude, and stereo panning for longitude, so you can hear roughly where countries, states, and cities sit relative to each other. Each country also has its own sound profile which helps tell neighbouring countries apart simply by listening to them. This is particularly engaging for young students who are learning about neighbours near and far in their Geography or HASS lessons.

3.1 Country sounds and custom sounds

Map in a Box includes a managed library of country and region sounds. Updates may add, replace, or remove files in that bundled library, including its attribution licenses file, credits.txt. Do not put personal sounds in the application or _internal folders, because those folders belong to the installed program and may be refreshed by an update.

To use your own sounds, place them in the user sound folders created by Map in a Box:

  • Windows portable: Data\sounds\countries or Data\sounds\regions, beside the portable program.
  • Installed Windows: %APPDATA%\MapInABox\sounds\countries or %APPDATA%\MapInABox\sounds\regions.
  • macOS: ~/Library/Application Support/MapInABox/sounds/countries or ~/Library/Application Support/MapInABox/sounds/regions.

Name a custom file after the country or region in lowercase, replacing spaces with underscores; for example, new_zealand.ogg or south_america.mp3. OGG and MP3 files are supported, with OGG preferred when both exist. On every launch, Map in a Box checks the user sound folders before the bundled library. Removing a custom file restores the bundled sound or normal regional fallback. Updates never alter the user sound folders.

3.2 Instructor-created maps

Select File, Create Map File to draw a simple map. Begin with a blank page or import a JPG, PNG, or PDF as a visual guide. A multi-page PDF can be imported as separate floors. Use the floor selector in the builder, draw the paths students may travel, select Add a place, click its position, and enter its name. Test a route, then save the portable .miabmap file. Select File, Edit Map File to change an existing map made from any supported source.

Select File, Open Map File to explore one. The arrow keys move only along connected drawn paths with spatial sound and announce nearby labelled entrances and places. Press Ctrl+Page Up or Ctrl+Page Down to explore another floor. Press Ctrl+Home or Ctrl+End for the top or bottom accessible point. Press Ctrl+R to choose two places, hear their crow-flight relationship, calculate a route that follows only the connected drawn paths, or explore that route with Journey Planner sound. Nearby but unconnected paths—such as parallel shopping-centre aisles—are never treated as connected. Press Escape to close the map file.

Closing the map file restores the previous world-map position. Street, Walking, and Free modes do not operate inside an instructor-created map.

4. Jumping to a place

Press J in map mode to open the jump dialog. Type what you're looking for such as a landmark, city or country, and press Enter. If there's more than one match, you'll get a list — arrow through it and press Enter to jump.

You can type:

  • City names — e.g. Brisbane, London, Vancouver
  • Countries — e.g. Japan, New Zealand, South Africa
  • Coordinates — decimal degrees, e.g. -27.47, 153.03
  • Geographic features — major deserts, mountain ranges, reefs, gulfs, capes, and other named natural features

For anything four characters or longer, a "Search online" option shows up at the bottom of the results list, and kicks in automatically if there's no local match. Online search goes through OpenStreetMap's Nominatim service and gives you a second list to choose from. Shorter terms with no local match just come back "not found". The Jump keystroke is disabled during the geography challenge game, since that would rather defeat the purpose!.

Map in a Box also quietly remembers your last five jumps, and stores them in a History list, which you can reach with Ctrl+H. This is handy if you've been bouncing between a few places and don't want to retype a search each time.

5. Marks

Marks are particularly useful when you want to know the rough distance between Point A and Point B. You can compare up to three places at once, without committing to a permanent favourite. Think of them as temporary locations, or sticky notes — numbered 1, 2, and 3 — that you can set, check back on, and clear whenever you're done with them.

To save one, move to the place you want to remember and press Ctrl+M. You'll be asked which slot to use — press 1, 2, or 3. To hear how far a mark is from where you are now, press Ctrl+1, Ctrl+2, or Ctrl+3. To jump back to one, press Ctrl+J and pick the slot if asked. Done with a mark? Press Ctrl+Shift+M and choose the slot to clear it.

You can press Shift+Alt+M to hear the distance and compass direction between every pair of stored marks at once.

6. Favourites

Favourites are for the places you'll want to come back to regularly. Unlike marks, these stick around permanently, saved locally across sessions.

Save the current place, or a point of interest you've found, and return to it any time from the favourites list.

7. Points of interest

Points of interest — POIs — cover businesses, transport stops, parks, medical services, accommodation, and landmarks. They come from OpenStreetMap by default; add a HERE API key and you get richer live detail like opening hours, phone numbers, and ratings on top.

They're useful in both map and street exploration — in map mode they tell you what's around, and in street mode you can inspect places one at a time. A good POI entry gives you an address, phone number, hours, and website, and that website is just one keystroke away.

When you open the POI list, you'll be asked to pick a category:

  • All nearby
  • Food and drink
  • Shopping
  • Public transport
  • Trains and stations
  • Health and medical
  • Community and services
  • Arts, venues and landmarks
  • Parks and outdoors
  • Accommodation

MapInABox can download relevant transport timetable information that can be browsed in an accessible list. So, if you pick a transit stop, you can often open departure information immediately if the timetable data is known to the program and can be downloaded.

Downloaded timetable data becomes stale after seven days. When a transport workflow next needs a stale feed, MapInABox asks whether to update it; choose No to use the existing timetable immediately. The Area Downloader is an explicit download action, so it refreshes stale feeds for the selected region without asking about each feed separately.

8. Find food

Find Food looks for food and drink venues along a route — handy for planning a stop on a longer trip. It lives in the Tools menu (F12) under Find Food; see section 14.9 for the full walkthrough.

You'll be asked for a starting point and a destination, and for each, the app offers a short menu which consists of the following options: type an address, pick a saved mark, choose a favourite, or use current location. Once both origin and destination are set, MapInABox fetches the route and attempts to list food and drink venues on-route in the order you'd pass them. It solves a problem a blind traveller often encounters on the road, who doesn't always know where their next meal is coming from!

9. Satellite and Street View

Map in a Box can pull up satellite imagery and street-level photographs for wherever you're standing. Both need a Google API key. Add a Mistral key as well, and the program will provide an image description.

9.1 Satellite view

Satellite view shows an overhead image of your current position in an in-app dialog. The Mistral description sits below the image and appears in a read-only dialog box. It can cover terrain, land use, buildings, water, and vegetation. If you don't have a Mistral key,, the image still opens, but the text field prompts that a Mistral key is required for descriptions.

9.2 Street View

Street View grabs up to two ground-level photographs of the current spot — one in each direction along the street — and shows them in an in-app dialog. Again, the Mistral description appears below the images and is announced by your screenreader, covering building types, street layout, signage, access features, and surroundings when a Mistral key is set. Without one, the images still load but the text just reads: "Street View imagery loaded. A Mistral API key is required to fetch a visual description."

The street-level imagery source can be selected in Settings. Google Street View is available when a Google API key is configured. Mapillary remains available with or without a Google key and opens in your browser. If Google Street View has no coverage where you are, it falls back to satellite view.

10. Street mode

Press F11 from map mode to drop into street mode at your current position. Street data comes from OpenStreetMap on demand and gets cached locally, so the first visit to an area can take a few seconds depending on your connection — after that, it's instant.

This is where the app shifts from overview to real-world detail: moving along roads, checking numbers and intersections, looking up businesses, and getting walking directions.

Movement follows the street network, with finer or larger steps when you need them. You can step through numbers and intersections, turn onto cross streets, search for a street or address, hear the nearest cross street, open the POI list, and ask for walking directions to a typed address. Press F11 again to head back to map mode.

Once you've asked for walking directions with Ctrl+G, you can normally step through them one instruction at a time. Press Shift+I instead, and — if you've got a Mistral key set up — the app will ask Mistral to generate an accessible narration for the walk, the way a local might describe it, rather than a list of turns. You then move through that narrative with Up and Down, repeat the current step with I, and press Escape to drop back into the ordinary step-by-step directions, with the route still active. If Mistral isn't configured, or the request fails, you just get the regular turn-by-turn list — nothing is lost by trying it.

MapInABox supports GNAF. GNAF (Geocoded National Address File) is Australia's authoritative address database, maintained by Geoscape. It contains millions of verified addresses, including precise street numbers, street names, suburbs and geographic coordinates. Unlike OpenStreetMap, where numbers depend on volunteer contributions and may be incomplete, G-NAF is compiled from state and territory government address data and is regarded as the definitive source for valid Australian addresses. For applications that need accurate street numbering, such as address lookup or navigation for blind users, G-NAF can be used to determine the exact location of a numbered property, validate that an address exists, and identify nearby street numbers with a much higher level of completeness and reliability than crowd-sourced mapping alone.

While browsing within Australia, Ctrl+Shift+F12 tells you whether GNAF address data is on or off; press it again within five seconds to flip it. GNAF tends to be better for residential numbers. On business strips, shopping streets, hotels, pubs, and other named venues, OpenStreetMap can actually do better, since businesses and buildings often carry their own address tags. If address stepping seems to skip past businesses or keeps landing on plain residential numbers, try turning GNAF off — then back on again once you're back among mostly houses.

11. Mass Downloading a city's suburbs

Normally street data is downloaded on demand. Press F11 and the current area loads there and then. That's fine for casual exploring, but there is generally a delay whilst the suburb data is fetched. If you already know you're going to spend a while in, say, Brisbane, or you'd rather not wait on a download mid-navigation, you can grab a whole batch of suburbs ahead of time instead.

Press Ctrl+Shift+F11 to open the Area Downloader. Choose a country and state or region, then either download its public-transport timetable data directly or find individual suburbs for street and address data.

  1. Country. Pick from a worldwide list — the country you are currently exploring ought to be auto-selected
  2. State, region, or postcode range. Choose a state/region from the list, or type a postcode range instead (useful when you want something more precise than a whole state).
  3. Suburbs. The app asks OpenStreetMap what real, named suburbs and towns actually exist in that area, and gives you a proper checkable list to choose from — arrow through it, tick the ones you want, and a filter box lets you narrow a long list down by typing part of a name. Nothing gets downloaded until you say so.
  4. Confirm. Review your selections and the estimated time, then start the download.

Once you confirm, the wizard closes and you are returned to the map, while the suburbs are downloaded in the background. It pays to avoid brand-new, un-downloaded areas while a batch download is running, since both would be competing for the same street-data connection and things would just go slower for a while. Anywhere you've already visited, or already downloaded, is unaffected.

Suburbs fetched this way are cached exactly the same as anything you'd visit normally with F11, so there's no difference once they're downloaded — walking into a pre-fetched suburb for the first time feels just as instant as revisiting somewhere you explored yourself yesterday.

12. Walking mode

Walking mode simulates moving along a real street network. You can travel forward and back along the current street and choose your turn at each intersection, with nearby points of interest optionally announced as you go.

Points of interest can be announced as you virtually walk, and these can be set up in the Settings menu (Control+Comma)

13. Free mode

Free mode lets you explore relative to a heading,. Best of all, you can move forward along your chosen path, and use the left or right arrow keys to hear points of interest on either side of the street on which you're travelling.

It's built for heading-based exploration: you can easily move forward or back, listen for nearby places on either side, snap to nearby cross streets, reverse direction, check address numbers or POIs, and step back into street mode whenever you're ready.

14. Tools menu

Press F12 in map mode to open the Tools menu — this is where the longer route and travel tools live. Some need marks, a destination, or an API key, and if a required key is missing, the app will let you know. If you're trying to plan, compare, or discover something, there's a good chance the answer is in this menu.

In Education, a computer administrator chooses which planning tools appear. Hotel Search, Virgin Australia Booking, and Order an Uber are never available in Education. Opening food websites, reviews, and menu links also remains unavailable.

14.1 Detour Calculator

Got time to drop off that parcel on the way to work? This tool Compares a direct trip against one with stop-offs added, showing the extra distance and time each diversion costs you.

  1. Enter your starting point.
  2. Enter your first stop-off, then your final destination.
  3. Add more stop-offs if you like — leave the prompt blank to finish.

Falls back to open routing without a Google key; turn-by-turn detail may be a bit thinner.

14.2 Suburb Lister

Lists alternative routes between two points, showing which suburbs or areas each one passes through and whether toll roads are involved.

  1. Enter your starting point.
  2. Enter your destination.

14.3 Shared Journey

Shared Journey helps two people decide where to meet before an event or where to part after it. The best choices are shown first.

Meet before an event

  1. Enter your starting place.
  2. Enter your friend's starting place.
  3. Enter the event location.

Map in a Box follows both journeys toward the event and looks for fair places where the routes come together. Each choice tells you roughly how long each person travels before meeting and how long remains to the event. Tab to Why these choices to read which side of the event each person approaches from and why the choices were made.

Drop off after an event

  1. Enter the event location.
  2. Enter your destination.
  3. Enter your friend's destination.

Map in a Box looks for places where your friend can drop you off without going far out of their way. Each choice tells you how far you travel together, how far each person has left, and whether the stop is already on your friend's way.

Sometimes both routes stay apart until close to the event. In that case, Map in a Box keeps the event as the simplest choice. It may also offer a few nearby alternatives when the routes are not far apart and there is still a useful journey to share. These alternatives clearly say that one person needs to make a short detour.

14.4 Toll Compare

Ever contemplate whether or not to take the tolls? How much time does it really save? This tool compares the toll route against the toll-free alternative for the same trip. Enter a start and destination; results show distance, travel time, and toll cost. Toll pricing needs a Google API key — without one you just get distance and time.

14.5 Journey Planner

Plans a public transport, walking, or driving route between two addresses, stops, cities, or coordinates.

  1. Enter origin and destination (address, stop name, or suburb).
  2. Choose transit, walking (for shorter trips), or driving.
  3. For transit, choose leave now, depart at, or arrive by, then enter a date and time if asked.

Transit results include connections, total duration, and per-leg departure times, as well as platform information where possible from GTFS data. Transit and walking results need a Google API key. Driving results include alternative routes, distance, duration, major roads, towns along the route, toll information when available, and spoken step directions. Driving uses open OSRM routing by default. When a Google key is configured, Settings displays a driving-source choice where paid Google traffic-aware routing can be explicitly selected. Merely storing a Google key does not enable Google driving requests.

For a driving or walking result, Tab to Explore Path to follow its geographic shape. Up and Down move along the route; Home and End jump to the endpoints. In driving routes, Page Up and Page Down move by larger sections. In walking routes, they jump between turn instructions and the path is sampled at walking scale. The optional spatial-audio checkbox tracks progress across the route. Escape stops the path audio, restores the previous map position, and returns to the journey results.

14.6 Departure Board

Shows upcoming departures for transit stops near your current position. Pick from a list of nearby stops; results include the service name, headsign, and departure time. You can also get here via Ctrl+Enter on a transit stop in the POI list.

Uses GTFS scheduled data by default. Add a HERE API key and it switches to live departures with platform numbers and real-time status.

14.7 Flight Search

Searches flights between two airports by name or IATA code, returning up to 15 itineraries sorted by duration — airline, departure and arrival times, and connections per leg. Needs a RapidAPI key (Timetable Lookup API, free tier available).

14.8 Hotel Search

  1. Enter a city.
  2. Select from the matched locations.
  3. Enter check-in and check-out dates.

Results aggregate hotels for the city with name and address for each. Pick one and it opens the hotel's own website, so you go straight from search result to the actual booking or info page. Needs a RapidAPI key (Priceline API, free tier available).

TripAdvisor reviews are also available when configured. Use the same RapidAPI key and subscribe to the Tripadvisor COM API, then choose Get TripAdvisor Reviews for a selected hotel.

14.9 Find Food

Find Food searches for food and drink venues within 300 metres (about 980 feet) of a route, in the order you'd pass them. Open the Tools menu with F12 and pick Find Food — it's one of the most practical examples of how the app turns a route into something you can actually act upon.

  1. Choose a starting point — type an address, pick a saved mark, choose a favourite, or use your current position.
  2. Choose a destination the same way.
  3. Map in a Box fetches the route and lists food and drink venues within 300 metres (about 980 feet) of it. Select one to hear its address; with a HERE API key you also get hours, phone number, and a website link.

Please note: If a GTFS transit route is already active you can press control+alt+f. This keystroke invokes a search which runs along that transit line instead of a road route, returning food places across the transit journey.

14.10 Order an Uber

Order an Uber hands a ride request to Uber with the pick-up point and destination already filled in. Open the Tools menu with F12 and pick Order an Uber.

  1. Choose a pick-up point — type an address, pick a saved mark, choose a favourite, or use your current position.
  2. Choose a destination the same way.
  3. Your browser opens Uber with both points set. Sign in to your own Uber account if asked, then choose a car type and confirm the ride in Uber itself. Car types and prices come live from Uber, so they are always current.

No Uber API key is needed and Map in a Box never sees your Uber account: the app only builds the link. Nothing is booked until you confirm inside Uber.

Tip: Uber's website works best when you are already signed in — if the pick-up and destination fields come up empty, sign in first and run the tool again. In Australia, Uber also takes bookings by phone on 13-UBER (13 82 37), with pre-booking up to 90 days ahead.

15. Geography challenge game

The challenge game tests your world geography by ear. The program names a country, and you have to find it on the world map using audio cues alone, and speed is the name of the game!

Note: Jump (J) is switched off during the challenge — no shortcuts allowed.

15.1 Audio cues

SoundMeaning
Map position toneThe normal spatial tone — tells you where you currently are on the world map.
Sonar pulseA centred pulse that rises in pitch as you get closer to the target country.
HeartbeatA low rhythmic beat that speeds up as the clock runs down.
FanfarePlays when you successfully find the target country.
BuzzerPlays when time runs out.

Fancy playing against someone else? Ctrl+F10 starts a scored, multi-player challenge session rather than a solo round — same audio cues, but now it's a competition.

Direction mode (Map learning or Shortest globe) is set in Settings under Challenge direction.

17. Internet and API keys

Much of MapInABox runs off local bundled data and doesn't need the internet at all. These are the components that do:

  • Weather and air quality
  • Timezone and sunrise/sunset
  • Wikipedia summaries
  • POI lookups and detail
  • Street data downloads
  • Transit timetable data
  • Route and navigation calculation
  • Flight and hotel search
  • Satellite and Street View imagery
  • Overhead flight information

17.2 Google and HERE in more detail

Google API key — enables satellite imagery and Street View inside the app as dialogs, not a browser tab. Satellite view shows an overhead image of your current position; Street View grabs up to two ground-level photographs of the location. Google Maps navigation gives turn-by-turn walking directions with named street instructions. Without a Google key, navigation falls back to OpenStreetMap routing, Street View falls back to Mapillary in a browser, and satellite imagery just isn't available.

HERE API key — entirely optional. Without it, the app runs on OpenStreetMap data throughout and works fine. With a HERE key, three things get better: POI details, HERE walking directions, and live departure boards. HERE accounts are free to create, but do need registration and might involve some follow-up contact from their commercial team.

Keystroke Manager

Open Settings, then choose Keystroke Manager to customise principal Map, Street, and Global commands. Search or browse the command list, then use Assign, Clear, or Restore defaults. Conflicting keys in the same context can be replaced after confirmation. Map and Street contexts may reuse the same key because only the active context runs.

The first version covers street-level and satellite imagery, jump, weather, POI and street search, address announcement, address navigation, walking mode, and route briefing. Context-sensitive movement and native menu accelerators remain fixed to protect arrow navigation and keep visible menu labels accurate.

18. Common workflows

18.1 Find a city

  1. Press J.
  2. Type the city name and press Enter.
  3. Choose from the results list if there's more than one match.
  4. Press Enter to jump.

18.2 Get facts about a country

  1. Move the cursor onto the country.
  2. Press F6 for area, population, and regional data.
  3. Press Shift+F1 for the capital city.
  4. Press L for languages, $ for currency.

18.3 Explore a neighbourhood at street level

  1. Jump to the city with J.
  2. Press F11 to enter street mode. Give it a moment to load.
  3. Use the arrow keys to move, S to search for a street by name, P for nearby POIs, A for address lookup, and Ctrl+G for walking directions.

18.4 Get ready to explore a whole city ahead of time

  1. Press Ctrl+Shift+F11 to open the Area Downloader.
  2. Pick a country, then a state/region (or a postcode range if you want a specific range, and if postcodes are supported in your region.
  3. Tick the suburbs you're interested in from the list, then press confirm.
  4. Keep doing whatever else you were doing — the download runs in the background, and each suburb loads instantly once it's done.

18.5 Plan food stops along a route

  1. Move to your departure point. Press Ctrl+M then 1 to save it as mark 1.
  2. Move to your destination. Press Ctrl+M then 2 to save it as mark 2.
  3. Press F12, choose Find Food, select mark 1 as the start and mark 2 as the destination, and look over the venues along the way.

18.6 Compare distances and directions between marked places

  1. Move to each place and press Ctrl+M, saving them as marks 1, 2, and 3.
  2. Press Shift+Alt+M to hear the distances and compass directions between all three.

18.7 Play the geography challenge

  1. Press F10. The program names a target country.
  2. Move with the arrow keys — the map-position tone tells you where you are, and the sonar pulse tells you how close you're getting.
  3. Press Shift+F10 at any time to hear the target name again.

18.8 Open a business website instantly

  1. Find a business in the POI list or in street mode.
  2. Press Ctrl+Alt+4 to hear the saved website field. In the Pro edition, Ctrl+W opens the site in your browser; external POI website launching is unavailable in the Education edition.
  3. Can't find a site straight away? The app falls back to a web search so you're not stuck.

19. Troubleshooting

19.1 First launch on macOS — app blocked by Gatekeeper

macOS blocks apps from developers who haven't paid for Apple's code-signing programme, which includes us for now. To open Map in a Box the first time, use the install script that comes in the zip:

  1. Extract the downloaded zip — you'll find MapInABox.app and install-macos.sh sitting together.
  2. Open Terminal (Applications → Utilities → Terminal, or search for it with Spotlight).
  3. Type bash (with a space after it), then drag install-macos.sh into the Terminal window and press Enter.
  4. The script clears the restriction, copies the app to your Applications folder, and opens it.

After that first run, you can open Map in a Box from Applications like any other app — no need to run the script again.

Or, if you'd rather do it directly in Terminal:

xattr -rd com.apple.quarantine /path/to/MapInABox.app

19.2 First launch on Windows — SmartScreen warning

Windows might show a SmartScreen warning the first time you run the installer, simply because the app hasn't built up a download history yet. This fades away as more people download it. To get past it:

  1. When the SmartScreen dialog appears, press Tab to reach More info and press Enter.
  2. Press Tab again to reach Run anyway and press Enter.

On macOS, use Command wherever the tables show Ctrl, and Option wherever they show Alt. For example, Settings is Command+,, refresh POIs is Command+Option+P, and the Area Downloader is Command+Shift+F11.

On the tested Mac, bare F11 was not delivered to wxPython even though other function keys worked normally. The verified alternative is:
