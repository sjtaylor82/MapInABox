Map in a Box feature comparison

This page compares the Pro and Education editions of Map in a Box. “Yes” means the feature is included in that edition. Some included features require an internet connection, an optional API key, suitable local map data, or a third-party account.

  • Map exploration and accessibility
  • Places, saved data, and POIs
  • Street, walking, and free modes
  • Location and environmental information
  • Travel and transport outside the Tools menu
  • Tools menu
  • Settings, data, and updates
